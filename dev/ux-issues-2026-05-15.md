# UI/UX Issues — 2026-05-15

Identified during hover audit and full UI/UX review of `v2-dev`.

---

## Open Issues

### UX-01 — No active/current-page indicator in sidebar
**File:** `flask_templates/macros.html`, `flask_templates/resource_base.html`  
On resource pages the sidebar shows Search, Chat, Edit — but nothing tells the user which page they are on. The "Edit sample" action in particular has no visual distinction when the edit panel is open. The sidebar actions should highlight the active context using `request.path` or a passed `active_url` flag.

### UX-02 — Right panel relationship items are dense on hover
**File:** `static/styles.css`, `flask_templates/resource_base.html`  
Both the copy-MFID button (📋) and the remove-relationship button (✕) appear on hover on the same row. On narrow viewports they can overlap or compete. The ✕ appears at the far right; the 📋 appears inline with the MFID. Consider hiding the copy button when in remove-confirmation state (`.rel-confirming`).

### UX-03 — `cg-sib-groupby` select has no hover state
**File:** `static/styles.css`  
The groupby dropdown in the resource card action strip (`.cg-sib-groupby`) has no CSS hover treatment, falling back to browser defaults. Inconsistent with everything else in the UI.

### UX-04 — Empty states are plain
**File:** `static/styles.css`  
"No relationships", "No samples match your filter", and similar empty states use raw icon + text with no background treatment. They look forgotten rather than intentional.

### UX-05 — Create panel: no visual grouping between field sections
**File:** `flask_templates/_create_panels.html`  
With many fields (Name, Type, Project, Timestamp, Public, Description, Relationships, Metadata), everything runs together vertically. No visual grouping between "identity" fields and "optional/advanced" fields makes the form harder to scan.

### UX-06 — `cg-action-btn` CSS class is dead code
**File:** `static/styles.css`  
`.cg-action-btn` and `.cg-action-btn.primary` are defined but not used in any main template. Should be removed to reduce CSS bloat, or documented if they are used by plugin views.

### UX-07 — Focus-visible states missing on custom interactive elements
**File:** `static/styles.css`  
`focus-visible` is set globally on `*` but custom interactive elements (`.cg-sidebar-action`, `.cg-rail-btn`, `.rel-remove-btn`, `.cg-sib-btn`, `.cg-drop-zone`) don't have explicit focus ring styles. Keyboard navigation and accessibility are broken on these elements.

### UX-08 — Mobile relationship sections use `<a>` tags inconsistently
**File:** `flask_templates/sample.html`, `flask_templates/dataset.html`  
The `d-xl-none` mobile relationship sections (Ancestors, Descendants, Linked Datasets, etc.) in sample.html use `<a class="list-row">` tags, while the project overview and other list rows use `<div onmouseup="navIfNoSelection(...)">` for text-selectability. Inconsistent pattern — UUIDs in `<a>` rows can't be text-selected without triggering navigation.

---

## Resolved Issues

### UX-02 ✅ — Right panel density: hide copy/remove buttons in confirming state
Added `.rel-item.rel-confirming .rel-copy-btn, .rel-item.rel-confirming .rel-remove-btn { display: none; }` so only the Remove/Cancel confirmation is visible when active.

### UX-03 ✅ — `cg-sib-groupby` hover + focus states
Added `transition`, `:hover` (accent border + body color), and `:focus` (accent border + soft shadow) to `.cg-sib-groupby`.

### UX-04 ✅ — Empty states tinted background
`.rel-panel-empty` now has `background: var(--cg-hover-bg)` and `border-radius`. Added reusable `.cg-empty-state` class with dashed border for use across the app.

### UX-05 ✅ — Create panel field grouping
Added `<hr>` dividers in both sample and dataset panels: one before the optional fields (Timestamp, Public, Description) and one before Relationships/Metadata.

### UX-06 ✅ — `cg-action-btn` not dead (used in user.html)
Confirmed used in `user.html` for API key actions. The `.primary:hover` hardcoded hex was already replaced with CSS token fallbacks in the hover audit.

### UX-07 ✅ — Focus-visible states on custom interactive elements
Added explicit `outline: 2px solid var(--cg-accent-mid)` focus rings to: `.cg-sidebar-action`, `.cg-rail-btn`, `.cg-sib-btn`, `.cg-sib-jump-btn`, `.rel-remove-btn`, `.cg-drop-zone`.

### UX-08 ✅ — Mobile relationship sections use navIfNoSelection
Replaced all `<a class="list-row" href="...">` in `sample.html` (linked datasets, ancestors, descendants) and `dataset.html` (linked samples, parent/child datasets) with `<div class="list-row" onmouseup="navIfNoSelection(...)">` so MFIDs inside are text-selectable.
